# Project 1 – SecureNova AI Identity Security: Threat Modeling

## Overview
This project focuses on identifying, analyzing, and assessing security threats in the proposed SecureNova AI Identity Security architecture.

## Objectives
- Understand the system architecture and data flows.
- Identify threats using the STRIDE methodology.
- Analyze potential attack scenarios using attack trees.
- Evaluate risks based on likelihood and impact.
- Map relevant threats to MITRE ATLAS techniques.

## Project Deliverables

### 1. Data Flow Diagram
Visual representation of the SecureNova architecture, identity components, data flows, and trust boundaries.

### 2. STRIDE Threat Assessment
Threat identification using OWASP Threat Dragon, focusing on potential threats in AI agent and MCP server interactions.

### 3. Attack Trees
- LLM API Key Exfiltration
- Agent Identity Spoofing
- RAG Chunk Poisoning

### 4. STRIDE Threat Matrix
A structured threat assessment covering Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, and Elevation of Privilege.

### 5. Risk Assessment
A risk register evaluating identified threats based on likelihood, impact, risk score, severity, and recommended mitigations.

### 6. MITRE ATLAS Mapping
Mapping relevant AI security threats to MITRE ATLAS techniques.

## Tools and Technologies
- OWASP Threat Dragon
- Microsoft Excel
- Draw.io
- MITRE ATLAS
- Git and GitHub

## Outcome
Developed a structured threat model for SecureNova, documenting potential security threats, attack paths, risk priorities, and recommended mitigations.
