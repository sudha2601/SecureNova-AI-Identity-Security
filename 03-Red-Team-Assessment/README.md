# Project 3 - SecureNova Red Team Assessment

## Overview
Security assessment of AI-powered applications and agent-based systems.

## Assessment Areas
1. Indirect Prompt Injection
2. Agent Identity Spoofing
3. System Prompt Extraction
4. Privilege Escalation
5. RAG Poisoning
6. MCP Security Assessment

## Assessment Methodology
- Controlled security testing
- Evidence collection
- CVSS 3.1 severity assessment
- MITRE ATLAS mapping
- Security recommendations

## Final Deliverables
- Test cases and results
- Screenshots and supporting evidence
- Risk assessment
- Final Red Team report
